## Overview

Bulk Editor is an open-source Python utility designed to automate bulk image processing, transformations, and computer vision workflows. Built on top of **OpenCV** and **Pillow**, it empowers developers, photographers, and content creators to apply complex transformations—resizing, conversions, cropping, filtering, and normalization—across large volumes of media in a single command.

## Computer Vision & Image Processing Features

- **Automated Batch Processing:** High-throughput processing pipeline handling folders of hundreds of high-resolution images concurrently.
- **OpenCV Transformations:** Utilizes OpenCV algorithms for precise pixel manipulation, aspect-ratio-preserving rescaling, and format optimization.
- **Developer-Friendly Interface:** Includes an intuitive Tkinter GUI alongside programmatic APIs for seamless integration into larger automation pipelines.
- **PyPI Published:** Distributed publicly as an easily installable Python package via `pip install bulk-editor`.
